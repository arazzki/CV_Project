# Muhammad Ariq Azzaki - Interactive CV Portfolio

A modern, interactive, and highly animated Curriculum Vitae / Portfolio website built with Next.js, Tailwind CSS, and Framer Motion. This project serves as a digital resume showcasing my projects, skills, certifications, and experience with a sleek glassmorphism aesthetic.

![Portfolio Preview](https://placehold.co/1200x630/151515/34d399?text=Ariq+Azzki+Portfolio)

## ✨ Features

- **Modern Glassmorphism UI:** Translucent cards, blurred backgrounds, and dark/emerald green theme for a professional yet cutting-edge look.
- **Interactive 3D Elements:** Hero section features an interactive 3D tilting profile avatar that reacts to mouse movements.
- **Fluid Animations:** Powered by `framer-motion` for smooth scroll reveals, stagger effects, and hover transitions.
- **Dynamic React Bits Components:**
  - **Chroma Grid:** Interactive spotlight masks applied to the project and experience sections.
  - **Star Border:** Animated glowing borders highlighting the profile avatar and call-to-action buttons.
  - **Logo Loop:** Infinite scrolling marquee displaying core technical competencies.
  - **Shiny Text:** Shimmering animated text for availability badges.
- **Fully Responsive:** Optimized for all devices from mobile screens to ultrawide desktop monitors.

## 🛠️ Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Animation:** [Framer Motion](https://www.framer.com/motion/) & GSAP
- **Icons:** [Lucide React](https://lucide.dev/)
- **Components:** [React Bits](https://reactbits.dev/)
- **Language:** TypeScript

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites
Make sure you have Node.js and npm installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/arazzki/cv-portfolio.git
   ```

2. Navigate to the project directory:
   ```bash
   cd cv-portfolio
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## 📂 Project Structure

- `src/app/` - Next.js App Router layout, global styles, and main page assembler.
- `src/components/` - Reusable UI components (Hero, Skills, Projects, Experience, Contact) and animated wrappers (ChromaWrapper, StarBorder).
- `public/` - Static assets, images, and resume files.

## 🌐 Deployment

This project is optimized for deployment on [Vercel](https://vercel.com). Simply import the GitHub repository into your Vercel dashboard and it will be deployed automatically with zero configuration needed.
